# GitHub setup checklist (10 minutes)

1. **Create the profile README repo.** New public repo named exactly `syedFaraz-hub` (same as your username). Add `profile/README.md` from this folder as `README.md`.
2. **Publish the flagship repo.** New public repo `agentic-rag-evals`, push the contents of `agentic-rag-evals/`.
   - Add the topics: `rag`, `llm`, `ai-agents`, `fastapi`, `tool-calling`, `evals`, `python`.
   - Set the About description: "Tool-calling RAG agent with hybrid retrieval, grounded citations, and an eval harness that gates CI."
   - Check that the Actions tab shows a green CI run, then add a status badge to the top of its README.
3. **Re-pin.** Pin `agentic-rag-evals` first. Then keep at most 2 to 3 of your better older repos (for example `Mystery-Message-NextJS-Nextauth-Express-Mongodb`, `Snappy-Chat-Socket-Application-MERN`). Unpin the Crypto/Movie/GPT-3 UI repos.
4. **Archive** (Settings > Archive this repository) the weakest tutorial-style repos instead of deleting them.
5. **Fix repo descriptions.** Correct the typos, and add one clear sentence plus a live link to each pinned repo.
6. **Profile bio.** Suggested: `Full Stack AI Engineer | LLM agents, RAG, Python, React/Next.js | Remote`
7. **Never publish client code** (Converge Labs, eSpark, Getweys). Link live products instead, as the profile README does.
8. **Keep it alive.** A commit now and then on the flagship repo (a new eval case, a real embedding model) keeps the activity graph from looking dormant.
